# Yorrity SEO Gen (Android APK)

1. Upload all these files to a new GitHub repository (Add file > Upload files).
2. Open the **Actions** tab and wait for "Build APK" to finish (about 3-5 minutes).
3. Open that run and download **YorritySEO-APK** from the Artifacts section.
4. Unzip it and install `app-debug.apk` on your phone (allow install from unknown sources).
